# 交付范围与判断

按题目授权自主判断，不等待业务答疑。只使用给定 CSV 和题目工时口径。

备选方案：仅做描述性分析（缺少行动）；训练复杂分类器（样本小、因果和上线依赖难解释）；核验前同步风险分流（选用，规则可解释且仅依赖已有时间字段）。

数据流：原始文件保留 → 严格校验与完全重复去除 → 时区统一 → 前五天校准、后两天回放 → 工时敏感性分析 → 同步清单和缺失标签追踪清单。

交付 Python 标准库脚本、自动生成的报告、根目录 README 与 AI_LOG。核验前规则读取两个时间字段与小组，评分和 Token 仅用于诊断/基线，不把标签用于分流。前五天校准阈值，再按训练期标记至少30条且情景收益为正选择适用小组。医疗组不适用。错误时间转人工确认，冲突 ID 拒绝分析。

成功标准：任何数字可重算，回放报告包含误报与漏报；将风险识别能力和同步真正修复失效的因果效果分开；不宣称离线回放已经节省实际工时。

验证覆盖：时区、阈值边界、非法时间、去重、冲突、标签缺失、收益公式、分流不依赖事后标签。原始数据只复制，不修改。
